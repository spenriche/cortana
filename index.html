    Stateless by design. Messages exist only in this tab's memory. No history, cookies, or localStorage, and no chat logs. The killswitch stores only an on/off adapter list. Closing the tab erases the conversation.

    How to use

    Start here

    1. Pick a model in the top bar. Uncensored / abliterated models are marked and chosen first.

    2. Type a message and press Enter. Shift + Enter adds a new line.

    3. Press Esc to stop a reply. + starts a fresh chat. Nothing is written to disk.

    Models

    The app scans your llama-swap stack on port 8080 and LM Studio on port 1234. Embedding and reranker models are hidden. Click the refresh arrows to rescan.

    Vision: image attachments need a vision model. Most Qwen models here include a vision projector; flint, qwen-flash and architect are text-only. Text and code files work with every model.

    Model guide: click the bar-chart button in the top bar to see what is loaded now and estimated rankings for questions, reasoning, coding, search/RAG, writing, vision, speed, and long context. Use any row's Use button to switch models.

    Attachments & screenshots

    • Click the paperclip to attach images or text/code files.
    • Paste a screenshot with Ctrl + V, or drag files onto the window.
    • Images are resized to 1600 px and sent to vision models. Text files are inserted into the prompt.
    • Limits: 8 attachments per message, 20 MB per image, 2 MB per text file (~28,000 characters, then truncated). PDFs and Office files are not supported yet.

    Reasoning & instant replies

    Use the Reasoning on/off pill under the composer, or Settings → Reasoning. With llama-swap, Off sends enable_thinking: false so the model skips its reasoning phase and answers immediately. On lets it think first.

    Models qwen-fast and qwen-4b are already configured as no-thinking variants in llama-swap. The change applies to the next reply.

    Tokens & speed

    The bottom bar shows live approximate tokens and tokens/second while a reply streams, then the exact count when it finishes. Hover a reply's token count to see time to first token.

    Copy, edit, regenerate

    • Copy any reply, or copy a fenced code block from its header.
    • Edit one of your messages, then Save & resend. Everything after it is replaced and the model answers the edited version.
    • Regenerate re-runs the latest answer without changing your message.
    • Message actions appear on hover; on touch screens they are always visible.

    Internet killswitch

    Click the Online / Blocked pill in the header. Windows asks for administrator permission, then every active network adapter is disabled. Local models keep working because 127.0.0.1 is never touched.

    The switch stays on after you quit. Reopen the app and click Blocked to restore internet, or re-enable the adapter in Windows network settings. If you are already offline it tells you there is nothing to block.

    Online status & your IP

    The header pill shows Online, Offline, or Blocked. When the connection returns you get a toast.

    Click Show IP for your public address plus ISP/org, city and local adapter addresses — useful for confirming a VPN or PeerBlock. The check is manual and contacts an external IP lookup service. If it fails, a blocker or VPN firewall may be in the way. On narrow windows, use Settings → Connection.

    Settings

    • System prompt — optional instructions, with a Direct preset.
    • Temperature — higher is more creative, lower is more focused.
    • Context window — Ollama only; llama-swap sets context in its config.
    • Add endpoint — connect any OpenAI-compatible local server.
    • Detected sources — shows what is online; Rescan refreshes it.

    Privacy

    Chat messages and attachments live only in this tab. There is no history, no localStorage, no cookies, and no request log. Closing or reloading the tab erases the conversation. Chat traffic stays on 127.0.0.1; the only external request is the manual IP check.

    The killswitch writes one small state file with adapter names, never conversation data.

    Troubleshooting

    • No models found — start the local AI stack (E:\ai\AI Launcher.vbs or start-swap-hidden.ps1), then click Rescan.
    • Image request fails — switch to a vision model such as qwen, qwen-9b or qwen-4b.
    • IP check fails — VPN killswitch, PeerBlock, firewall, or no internet. Local IPs still appear.
    • Killswitch left on — reopen the app and click Blocked, or enable the adapter in Windows.
    • LM Studio missing — make sure its server is running and CORS is enabled.

    Everything runs on this PC. The full guide is also in HOW TO USE.md next to the launcher.
